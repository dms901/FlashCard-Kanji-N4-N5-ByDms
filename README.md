# Master Kanji N3 🇯🇵

Aplikasi web flashcard untuk belajar 700+ Kanji JLPT N3. Dibuat dengan Vanilla JS + Tailwind + Supabase.

## ✨ Fitur
- **Sistem Auth**: Login/Register dengan Supabase
- **28 Bagian**: Materi N3 dibagi per part biar gak overload
- **Flashcard 3D Flip**: Klik untuk lihat Arti dan Bacaan
- **Tracking Progress**: Tandai kanji yang sudah hafal + progress bar
- **Shuffle & Preview**: Acak kartu dan lihat semua kanji dalam 1 bagian
- **Responsive**: Dioptimalkan untuk HP

## 🛠️ Tech Stack
- HTML5, CSS3, JavaScript ES6
- Tailwind CSS via CDN
- Supabase Auth
- Font: Plus Jakarta Sans

## ⚙️ Cara Jalanin
1. Clone repo
2. Buka `index.html` di browser
    *Catatan: Butuh ganti SUPABASE_URL dan SUPABASE_KEY di dalam file JS*

## 🚨 Penting
Jangan lupa ganti Supabase Key sebelum deploy ke public.
